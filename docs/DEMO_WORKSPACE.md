# Demo Workspace

Local Work OS can create an optional demo workspace from the Welcome screen. The
fixture is generated entirely on the local machine and uses fictional names,
`example.test` links, generated Markdown attachment content, local tags,
categories, saved views, relationships, projects, contacts, tasks, notes, and
lists.

The generator exists for reviewers and first-run testers who need realistic data
without importing private files. It does not copy proprietary assets, connect to
cloud services, fetch remote metadata, or enable telemetry.

## Manual QA

1. On the Welcome screen, enter a new local folder path.
2. Choose **Create demo workspace**.
3. Confirm the app opens the workspace and Dashboard/Today/project/contact
   surfaces show sample records.
4. Search for `demo` or `@demo` and confirm generated items appear.
5. Open the Launch Readiness project and verify the local demo brief attachment
   can be found under the workspace `attachments/` folder.
