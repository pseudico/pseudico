# Release Audit Artifacts

This folder contains local release-readiness evidence generated by repository
commands.

- `dependency-license-audit.json` is generated by `pnpm audit:dependencies`.
- `THIRD_PARTY_NOTICES.md` is generated by `pnpm audit:dependencies`.
- `package-artifact-check.json` is generated by
  `pnpm release:package-check` after `pnpm package`.

These files are evidence for operator/release readiness. They do not replace
owner legal review before public distribution.
